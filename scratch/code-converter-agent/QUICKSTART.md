### 📝 How to Use

1. **Click "Import iOS File"** (or "Import Android File")
2. **Select a code file** (.swift, .kt, .java, .m, .h)
3. **Click the dropdown** to choose conversion direction if needed
4. **Click "Convert to Android"** (or "Convert to iOS")
5. **Wait for the AI** to convert your code
6. **Copy the result** with the copy button
